# 0001 Stack

Status: accepted (set by the project owner).

Avalonia for UI, G3MLib for data files, .NET 10. Avalonia 12.1.x matches G3MTool GUI, so styles and services can move between the two apps.

G3MLib is GPL-3.0-only because it includes UndertaleModLib-derived code. G3MStudio links it, so G3MStudio is GPL-3.0-only. Every dependency must be GPL-3.0 compatible.
