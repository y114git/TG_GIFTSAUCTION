# Modder wishes and gaps

Status: done 2026-11-04. Question: what do UndertaleModTool (UTMT) users ask for and complain about most, and where does G3MStudio stand? Inputs: [../status.md](../status.md), [../design/parity-coverage.md](../design/parity-coverage.md), [utmt-scripts-analysis.md](utmt-scripts-analysis.md), the Studio code, and the issue tracker of UTMT.

## Method and limits

- Main source: the issue tracker of UnderminersTeam/UndertaleModTool, read through the GitHub search API on 2026-11-04. Issues were ranked by comment count and by thumbs-up reactions, then grouped by theme. The API hit its rate limit during the run, so the last keyword sweeps (lag, freeze, reference) were not done.
- Reaction counts on UTMT issues are tiny. The highest thumbs-up count found is 4 (issue 360, dark mode). Most requests have 0 to 2. Comment counts are the better signal and are quoted below as "N comments". Numbers are as read on that date and will drift.
- Web search for Reddit threads (r/Undertale, r/Deltarune, r/PizzaTower), mod merging or conflicts, and tool comparisons found no usable thread. Not found: any Reddit post, any GMTools comparison, any count of users. Two weak hints only: Pizza Tower mods are shared as xdelta patches applied by a mod manager called Pizza Oven ([itch.io comment page](https://itch.io/profile/jaykaywahoo)), and some mods need a specific nightly UTMT build (same page). A [Deltarune forum thread](https://deltaruneboards.jcink.net/index.php?showtopic=2451) says there is little written documentation for modding with UTMT. [LibHunt](https://www.libhunt.com/r/UndertaleModTool) lists only YYToolkit and DogScepter as related tools, not full replacements.
- "Evidence" below means issue comments and reactions, not a survey. Some wishes may be common but rarely filed as issues (for example mod merging).
- Studio state was checked in code (file named) or in the design docs (doc named). "Spec only" means a design document describes it and no matching code was found by search. Features were not run for this report, so "done" means built, not proven on every game.

## 3. Notes

- Most top-voiced wishes are already built in Studio. The weak spots are load robustness on new games, code editor speed, GIF export and Linux and macOS proof.
- Mod sharing (patches, merge conflicts between two mods) has almost no filed issues, so it is not ranked here. Studio has patches and mod packaging specs ([patches.md](../design/editors/patches.md), [mod-packaging.md](../design/editors/mod-packaging.md)); whether modders want more was not found.
- The tracker excludes anything discussed only on Discord, which is where the Underminers community is said to answer questions. That gap could not be searched.
